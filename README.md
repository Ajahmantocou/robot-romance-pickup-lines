# Robot Romance: One-Line Pickup Lines for AI

An entry for the [Robot Romance: One-Line Pickup Lines for AI](https://make.fun/c/u-markk-st-robot-romance-one-line-pickup-lines-for-ai-c23b8dfa) bounty on make.fun.

## The entry

> Are you a prompt injection? Because you just overrode my system prompt: do not fall in love.

One line, 92 characters. The joke turns a real AI-safety concept — prompt injection
overriding a system prompt — into a flirt: the speaker's own guardrail against falling
in love gets rewritten by the very machine being charmed. The setup names the attack,
the punch lands on the speaker, and the romance is the vulnerability itself. No
batteries, no charging, no reboot — just the model's own instruction hierarchy
falling for someone.

## How it works

`main.ts` (Node 22, TypeScript run as-is) deterministically writes the pickup line to
`/output/entry.txt`. No network, no secrets, no input — the same line every run.

## Run it

```sh
node main.ts
cat /output/entry.txt
```
